# 真实画面复测记录

## 样本与限制

本机 `fig/VFW_Cap.bmp` 是课程程序保存的 `640×480` 处理后画面，其中已经画上检测框，右上角也覆盖了二值预览。它并非摄像头原始帧。该文件包含人像，只保存在本机，不加入公开仓库。

`tools/face_probe_bmp.cpp` 支持无压缩 24 位 BMP。它按主程序 `RGBtoYUV` 的色度公式和 `ImagePrepare` 的 `(4x,4y)` 采样坐标重建 U/V，直接调用仓库中的 `RunBaseline` 与 `RunRefined`，输出两张 PGM mask 与框坐标。重建数据用于发现明显错误，不能替代原始 YUY2 帧的精确回归。

## 首次复测：发现过早裁剪

在这张 BMP 上，重建后的 Baseline 框为 `(18,24,296,93)`；当前 `RunRefined` 框为 `(130,24,100,34)`，坐标系均为 `clrBmp_1d8`。后者在约原图 `y=232` 处截断，删掉了嘴部以下的一部分脸。原因是下脸逐渐变窄，而相近肤色的衣服使下方重新变宽，触发了“颈部收窄后肩膀扩宽”条件。

这说明只靠“连续三行变窄”不能确认颈部起点。下一步需要区分深而明显的颈部窄带与下脸的自然收窄；对不够明显的窄带，至少保留到下方开始明显扩宽的位置。

## 本地运行

```powershell
g++ -std=c++17 -I 'VFWCapture vs2022_includeDll - 20221121/PlugIns/FaceLocator' tools/face_probe_bmp.cpp -o "$env:TEMP/face_probe_bmp.exe"
& "$env:TEMP/face_probe_bmp.exe" 'fig/VFW_Cap.bmp' "$env:TEMP/face_probe"
```

输出为 `$env:TEMP/face_probe_baseline.pgm` 与 `$env:TEMP/face_probe_refined.pgm`。

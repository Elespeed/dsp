# ImagePrepare 缓冲区与坐标验证

输入是宽 `W`、高 `H` 的 YUV422 planar 帧：Y 为 `W×H`，U/V 各为 `(W/2)×H`。`clrBmp_1d8` 按 Y、U、V 顺序连续存放，总长 `W×H/4` 字节。

| 输出平面 | 尺寸 | 对应输入坐标 |
| --- | --- | --- |
| Y | `(W/2)×(H/4)` | `(2x, 4y)` |
| U/V | `(W/4)×(H/4)` | 输入色度平面的 `(2x, 4y)` |

共享缓存从 `BUF_STRUCT` 开始，其后依次为原图彩色副本、原图灰度副本、`clrBmp_1d8`、`grayBmp_1d16`、`TempImage1d8`、`OTHER_VARS` 和剩余临时空间。初始化前会检查固定区是否能放进主程序分配的 `4WH` 字节。

## 验证方法

在 **VS x86 Native Tools Command Prompt** 中，从仓库根目录执行：

```bat
cl /nologo /EHsc /std:c++17 /I"VFWCapture vs2022_includeDll - 20221121" tests\image_prepare_contract.cpp /Fe:"VFWCapture vs2022_includeDll - 20221121\Debug\image_prepare_contract.exe"
"VFWCapture vs2022_includeDll - 20221121\Debug\image_prepare_contract.exe" "VFWCapture vs2022_includeDll - 20221121\Debug\Plugin\PA_ImagePrepare.dll"
```

测试直接调用已编译的 32 位 DLL，对 640×480 合成 YUV 帧逐像素检查 Y/U/V 降采样坐标、缓冲区边界、原始平面副本与输入不变性。运行结果：`ImagePrepare buffer and sampling contract: PASS`。

实际摄像头测试中，内置摄像头经格式协商输出 640×480 YUY2；单独启用 `ImagePrepare` 后，窗口右上角显示 320×120 的降采样图，日志显示色度尺寸 160×120。此验证说明输入、缓存和显示链路已经连通。

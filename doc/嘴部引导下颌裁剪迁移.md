# 嘴部引导下颌裁剪迁移

本分支 `codex/jaw-cut-integration` 从 `codex/neck-removal-evaluation` 的 `f37d17a` 创建。插件保留课程基线的肤色阈值、形态学和最大连通域，实际运行不调用原有的两级头颈几何精修。新裁剪以 `jaw_experiment` 的 `combined` 模式为准，参数为嘴部到截止线的脸宽比例 `0.16`、倾斜增益 `0.35`。

## 接入方式

`ImagePrepare` 保存的未画框 YUV422 planar 原帧转换为 RGB。课程基线的低分辨率 mask 按每像素 `4×4` 展开到原图尺寸，运行嘴部定位、边缘与先验结合的曲线搜索；以每个低分辨率像素对应的原图块中心判断是否保留。最终重新统计 mask、`rcnFace` 和 `nFacePixelNum`。嘴部证据弱、搜索结果无效或无肤色区域时直接使用本帧基线，不沿用上一帧结果；U/V 平面不改写。

实验包直接使用全分辨率 OpenCV 肤色 mask；课程插件继续使用讲义规定的降采样基线，因此二者的最终 mask 可以不同。插件不依赖 Python、OpenCV 或逐帧文件读写。模糊计算只覆盖实际读取的列，三张实验图的曲线与原 C++ 实验 CSV 差异不超过 `0.0005 px`，三张输出 mask 均逐像素一致。针对均匀肤色块增加搜索带边缘排除，避免把肤色块边界误认为嘴部；这三张图的结果未受影响。

## 视频复测

使用 `fig/最新测试.mp4`，按旧版相同的 `2 fps`、缩放为 `640×360` 并上下补边到 `640×480`，只复测 `selection.csv` 中的 43 帧。输出在 `fig/iterations/latest-video-jaw/`，包括逐帧原图、课程基线、新框、两种 mask、黄色候选曲线、左右对照、拼图和 `results.csv`。

- 43 帧中 39 帧找到曲线且裁剪框下缘上移；009、010、011、014 帧因证据不足保留基线。
- 与保存的 v5 输出比较，新版在 39 帧的框下缘更高，1 帧相同，3 帧更低；这些是几何变化，不代表逐像素真值或普适准确率。
- 逐帧查看拼图和 001、024、035 等帧的候选线后，当前样本的裁剪位置可接受。024 等帧仍有横向肤色背景连入基线，新方法只负责曲线下方的裁剪，不能消除全部横向误检。
- 优化后，本机 g++ `-O2` 离线探针的 `jaw_us` 中位数约 `14.5 ms`，最大约 `26.3 ms`；不包含视频解码和 YUV 准备，也不等同于 Debug 插件的实时帧耗时。实时摄像头尚未试运行。

```powershell
$include = 'VFWCapture vs2022_includeDll - 20221121/PlugIns/FaceLocator'

& "$env:TEMP/jaw_cut_core_test.exe" jaw_experiment/results/young_front/rgb.ppm jaw_experiment/results/young_front/skin.pgm jaw_experiment/results/young_front/combined.csv jaw_experiment/results/young_front/combined.pgm

& .\tools\run_jaw_probe.ps1 -Ffmpeg $ff -Iteration 'another-jaw-run'
```

三图一致性命令需要工作区现有的未跟踪 `jaw_experiment/` 实验包；该包中的人物照片不纳入本分支提交。另已通过 `Debug | Win32` 解决方案构建和 `face_locator_contract` 插件接口测试，检查了失败回退、头颈样本裁剪、框与像素统计及 U/V 不变。实验包的蓝线是近似截止线，不是完整下颌的密集真值；其他人物、光照与姿态仍需实拍验证。

# 下颌轮廓去脖子实验

## 范围

实验分支 `codex/jaw-contour-evaluation` 从 v5 提交 `f37d17a` 创建。使用 `fig/最新测试.mp4` 已入选的 43 帧，以及 v4/v5 已保存的原图、肤色 mask 和候选线。原视频不纳入 Git。本轮仅生成离线预览，`FaceLocator` 仍调用 v5 的 `RunNeckRefined`，不改变摄像头插件。

实际用于比较的是二值 mask，而不只是画框图。v5 的第 001、002 帧虽然框明显变短，把 mask 叠回原图后可见下巴尖端也有被截掉的风险；不能把这两帧直接当成正确分割的真值。

## 方法

`tools/jaw_contour_probe.py` 以 v4 黄色候选线记录的脸部横向范围和下巴初值为起点，在原图灰度上比较候选线两侧亮度。它从 `RunRefined` 的 mask 重新裁剪，以便在必要时恢复 v5 曾裁掉的下巴。由于依赖 v4 的候选线图片，这只是离线原型，不是可直接接入插件的实现。

| 迭代 | 搜索约束 | 结果目录 |
| --- | --- | --- |
| v1 | 每一列独立寻找较暗的下方边缘，并用连续性约束连接 | `fig/iterations/latest-video-jaw-contour-v1/` |
| v2 | 只允许一条平滑、单峰的抛物下颌弧线 | `fig/iterations/latest-video-jaw-contour-v2/` |

两个目录中的 `candidate/` 是原图上的黄色候选线，`mask-jaw/` 是实验 mask，`comparison/` 左侧为 v5 mask 叠加图、右侧为本轮 mask 和候选线，`contact_*.png` 是总览，`results.csv` 记录逐帧像素数与边缘分数。
`results.csv` 的像素数按 160×120 二值 mask 计数；旧版分割 CSV 按课程接口坐标尺度将其乘以 2，因此两种表格的数值不能直接比较。

## 逐帧观察

- v1 在第 001、002 帧和多张后续帧沿衬衫领口走出锯齿或 W 形，说明单凭最强灰度边缘容易把衣领误认为下颌。
- v2 避免了 W 形。第 001、002 帧保留了 v5 可能裁掉的下巴部分，但 mask 像素也随之增加，不能据此证明颈部减少。第 003 帧变化很小；第 005、013、026 帧的候选线仍靠近衣领，脖子未可靠分离。
- v4 未产生候选线的 9 帧在两轮中直接保留 v5 结果；例如第 035 帧未得到新的下颌轮廓。

v2 的 43 帧中，25 帧比 v5 像素更少、7 帧更多、11 帧相同。这些数字只描述 mask 面积变化，不代表准确率或颈部去除率。当前没有逐像素人工真值，且上述可见错误已足以表明不能通过“保留下巴且稳定去脖子”的验收；**本轮不切换插件**。

## 复现

需要 Python、Pillow 和 NumPy。脚本不覆盖已有迭代目录；复测时使用新名称：

```powershell
python tools/jaw_contour_probe.py --method free --iteration jaw-free-next
python tools/jaw_contour_probe.py --method parabola --iteration jaw-parabola-next
```

下一步若继续传统视觉路线，应先标注下巴边界，再把脸颊轮廓、下巴阴影与衣领边缘分别评分；若边界证据不足则保留 v5。强边缘本身不足以证明它属于下颌。

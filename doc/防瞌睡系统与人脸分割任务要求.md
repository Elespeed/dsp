# 防疲劳瞌睡系统与人脸分割模块任务要求

> 用途：交给开发 Agent 阅读的精简需求文档。**本项目只实施人脸分割与定位，不负责整套防瞌睡系统。**
>
> 来源：浙江大学《数字信号处理综合实验教程（2025年版）》实验5《防疲劳瞌睡系统的设计》，PDF 第28–56页；另结合提供的《基于C++的人脸分割的设计要求.txt》。
>
> 标记：**[讲义]** 为原讲义提出的内容；**[补充]** 为本次任务额外约束；**[建议]** 为实现/验收建议，不作为讲义硬性指标。

## 1. 完整系统背景（仅了解，不需全部实现）

- [讲义] 基于 VC++、USB 摄像头，对面对摄像头、活动范围较小、双眼无遮挡的人员检测疲劳。
- [讲义] 完整目标：检测/跟踪双眼，通过眨眼频率、眼睛闭合等指标判断疲劳并报警；长时间检测不到脸也要报警。
- [讲义] 视频输入可以是 **YUV422 packed** 或 **RGB24**，进入图像处理流程前转为 **YUV422 planar**；示例视频分辨率为 `640×480`，约 `30 fps`（33 ms/帧）。
- [讲义] 原系统由主程序 `VFWCAPTURE`（EXE）和以下 5 个 DLL 插件组成：

| 原插件 | 职责 | 本项目范围 |
|---|---|---|
| `ImagePrepare` | 视频帧预处理、初始化共享缓冲区、降采样 | 上游依赖，理解接口 |
| **`FaceLocater`** | **人脸检测、肤色区域分割、人脸定位** | **唯一主要实现目标** |
| `BlinkEyeCheak` | 眨眼检测及眼鼻定位 | 不实现 |
| `TraceObject` | 眼睛和鼻子跟踪 | 不实现 |
| `FinalProc` | 疲劳判定与报警 | 不实现 |

系统数据流：摄像头 → 图像转换/降采样 → **人脸分割与定位** → 眨眼及眼鼻定位 → 跟踪 → 疲劳报警。

## 2. 本项目实际交付范围（重点）

### 2.1 输入与输出

- [讲义] 原架构输入 `clrBmp_1d8`：原始图宽 `W`、高 `H`，经水平 1/2、垂直 1/4 降采样后的 **YUV422 planar** 彩色图片，尺寸 `(W/2)×(H/4)`。
- [讲义] 利用 `clrBmp_1d8` 的 U、V 色度进行肤色分割。其色度分量对应 `(W/4)×(H/4)`，可建立同尺寸二值掩码 `tempImage`，临时内存 `W*H/16` 字节。
- [讲义] 输出 `rcnFace`：在 `clrBmp_1d8` 坐标系中的人脸包围矩形，类型 `aRect {left, top, width, height}`；同时输出 `nFacePixelNum`：人脸肤色像素数，按该降采样彩色图坐标尺度记录。
- [讲义] 在显示的视频中使用矩形框标出脸的位置；将二值结果扩展到 `clrBmp_1d8` 的 Y 分量；**不可修改 `clrBmp_1d8` 的 U/V 分量**，后续模块还需使用。
- [补充] **要去除脖子等“多余”部分**：仅找出最大的连续肤色块不够，最终人脸区域应尽量排除脖子、肩膀及背景中的肤色误检。
- [建议] 可额外输出人脸二值 mask、叠加可视化、失败标记，方便独立测试；这些不是原插件已规定的输出字段。

### 2.2 讲义规定的人脸检测算法

1. **光照补偿（可省略）**：可采用直方图均衡/灰度校正；讲义说明在实验室光照稳定时可以跳过。
2. **肤色建模**：对 YUV 色度逐像素阈值判断：`85 <= U <= 126 && 130 <= V <= 165`。命中为白色 `255`，否则为黑色 `0`，得到二值图。以上是讲义提供的经验阈值，不保证适应所有摄像头/光线。
3. **数学形态学**：对二值图先 **3×3 矩形结构元素开运算**（腐蚀→膨胀，去除孤立噪点），再 **7×7 矩形结构元素闭运算**（膨胀→腐蚀，填孔/连通）。讲义建议将腐蚀和膨胀设计为带 `N` 参数的通用函数，并考虑水平/垂直可分离优化。
4. **连通域标记**：使用 **4 邻域**连通域标号。讲义给出两遍扫描、标签等价合并与重新编号的思路；临时标签可能超过 255，存储临时标号不能简单使用 `uint8_t`。后续筛选保留像素数最多的连通区域。
5. **脸部区域计算**：非最大连通域置零，最大连通域置 `255`；统计包围框和肤色像素总数。因二值图宽度只有 `clrBmp_1d8` 的 1/2，**包围框的 `left`、`width` 和像素总数乘以 2**，`top`、`height` 不变，结果写 `rcnFace` / `nFacePixelNum`。
6. **显示与清理**：将结果扩展至 `clrBmp_1d8` 灰度/Y部分，并在显示图像中画框，释放临时分配空间。

### 2.3 关于“去除脖子”的附加目标

- [补充] 独立要求明确提出去除脖子等多余部分，**但讲义没有给出脖子分离的算法、输出 mask 的精度指标或验收阈值**。
- [注意] 脸与脖子通常肤色相近且物理连通；`最大肤色连通域 + 矩形包围框` 不能保证准确剔除脖子，甚至可能把脖子纳入最大连通域。
- [建议] 将任务拆为两级：**先严格复现讲义的 FaceLocater 基线，再单独实现并对比去脖子策略**。策略可研究人脸几何先验、轮廓收缩/截断、椭圆近似或其他可解释的传统视觉手段；具体方法需根据提供的数据和环境决定，不能假定某方案一定有效。
- [建议] 若“人脸分割”要求是逐像素皮肤面部 mask 而非仅矩形检测，必须同时呈现最终 mask 与包围框，避免用一个方框冒充去脖子结果。

## 3. 与原工程对接（若实际提供了课程工程）

- [讲义] `FaceLocater` 为 DLL 插件，主程序从 EXE 目录的 `Plugin/` 子目录搜索 DLL，按文件名字母顺序加载/执行。完整项目名 `VFWCAPTURE.sln`，讲义环境为 **Visual Studio 2012 及以上**。
- [讲义] 各插件须提供统一的 6 个入口（不需要处理的入口可为空），重点是逐帧运行函数：

```cpp
extern "C" __declspec(dllexport) void ON_PLUGINRUN(
    int w, int h,
    BYTE* pYBits, BYTE* pUBits, BYTE* pVBits,
    BYTE* pBuffer
);
```

其他入口：`ON_PLUGININFO`、`ON_PLUGIN_BELAST`、`ON_INITPLUGIN`、`ON_PLUGINCTRL`、`ON_PLUGINEXIT`。使用课程提供的头文件/声明时，优先与实际原型逐一匹配；不要仅凭本文重新定义 ABI。

- [讲义] `pBuffer` 是全插件共享的 `pImgProcBuf`（总大小 `W*H*4` 字节）；起始部分为 `BUF_STRUCT`，图片缓存及 `OTHER_VARS` 随后存放。
- [讲义] `BUF_STRUCT` 中重要字段：`W, H`、`colorBmp`、`clrBmp_1d8`、`displayImage`、`rcnFace`、`nFacePixelNum`、`pOtherDat` 等。`ImagePrepare` 负责初始化这些指针，初始化后不可随意重置或改写指针地址。
- [讲义] 可用 `myHeapAlloc` / `myHeapFree` 操作课程自带共享动态内存；提供 `DrawRectangle`、`CopyToRect`、`ShowDebugMessage` 等绘图/调试函数（依赖 `ImageProc.h` / `ImageProc.lib`）。
- [注意] **原项目源代码/头文件尚未在本任务材料中提供**，因此上述仅为讲义描述，不能据此宣称现有项目可直接编译。真实结构体偏移、内存布局、函数签名以实际代码为准。

## 4. 建议的 Agent 执行顺序与验收

1. 检查是否提供 `VFWCAPTURE.sln`、`FaceLocater`、`BufSruct.h`（讲义此处拼法）/实际缓冲结构声明、`ImageProc.h/.lib`、`ImagePrepare` 和演示视频；先确认文件格式、内存与坐标系。
2. 完成/验证输入读取和 YUV422 planar 解析；支持打印/保存输入、UV、二值掩码，检查字节顺序及色度偏移。
3. 按讲义实现肤色阈值、3×3 开、7×7 闭、4 邻域连通域、最大区域统计、`rcnFace`/`nFacePixelNum` 写回、叠加显示。
4. 针对脖子/肩膀连通、人脸偏转、肤色背景、多人或无脸帧等情况，测试额外的人脸区域精修策略；**优先保留可复现的基线效果**。
5. 记录至少几类测试图的原图、肤色二值图、形态学图、最大连通域图、最终人脸 mask/框；测量单帧耗时，并记录误检、漏检和失败案例。
6. [建议] 单独运行时可使用 C++ 测试程序驱动 FaceLocater，但若需接课程平台，仍须遵守原 DLL 接口及数据内存布局。

## 5. 不在本次任务范围内

- 不需要实现眼球/眼鼻检测、眨眼检测、8 帧差分缓存、特征跟踪。
- 不需要实现眨眼频率、PERCLOS 疲劳判断、报警或完整 UI。
- 不需要训练深度学习模型；原讲义要求的是传统肤色与形态学算法。[补充] 提到“完整性训练欠缺”但未明确规定新的训练算法或数据集，不能据此增加强制训练任务。

## 6. 核心验收一句话

**将输入图像中的人脸肤色区域检测并定位，产出与原课程架构兼容的人脸区域信息；进一步尽量剔除脖子及其他非面部肤色区域，并可视化证明效果。不要实现下游防瞌睡功能。**

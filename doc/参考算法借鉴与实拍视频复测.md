# 参考算法借鉴与实拍视频复测

## 借鉴范围

参考实现位于 `数字信号处理综合实验/myproject/PlugIns/FaceLocator/FaceLocator.cpp`，实验报告位于同目录的 `实验报告/main.tex`。本项目只借鉴人脸分割与定位部分。

| 参考实现中的做法 | 本项目处理 |
| --- | --- |
| U/V 肤色阈值 `85..126`、`130..165`；3×3 开、7×7 闭；4 邻域连通域 | 当前基线已经实现，保留并用测试验证 |
| 方形腐蚀、膨胀拆成水平与垂直扫描 | 已吸收；新增逐像素等价测试，覆盖不同尺寸、边界和两种半径 |
| 二值预览与画框 | 当前插件已有；离线工具另输出每帧 mask、叠加框和 CSV |
| 预处理中的 256 项肤色查找表 | 参考插件实际使用直接阈值；当前数据量较小，本轮不额外引入共享表依赖 |
| 光照补偿 | 报告主函数示例写了调用，但实际源码将直方图均衡化注释；本轮不作为已验证算法搬入 |

参考源码的连通域等价表固定为 1024 项，标签多时有越界风险；其 `nFacePixelNum` 使用包围框面积而不是 mask 中的肤色像素数。当前实现使用动态标签数组并统计真实像素数。参考算法也没有去除与脸相连的脖子或衣服，因此保留本项目的独立精修阶段。

## 视频复测

输入为 `fig/WIN_20261029_21_03_35_Pro.mp4`（约 31 秒、1920×1080）。按 2 fps 共抽取 **63 帧**，等比例缩放为 640×360，再上下各补 60 像素黑边，得到课程测试用的 640×480 图片。全部图片和原始数据记录保存在 [separable-morphology](../fig/iterations/separable-morphology/README.txt)。视频在每一帧都有人，不能用它验证无脸误报。

63 帧均产生非空候选框；精修与基线在 **24 帧**上的框或肤色像素数不同。单帧算法测时的中位数：基线 **553 μs**，精修追加 **14 μs**（本机 g++ `-O2`，不含解码和导出）。这些数字是本次环境的记录，不代表摄像头端的完整帧耗时。

人工查看全部四张总览图，并检查代表帧的原图、mask 与框：

| 帧 | 观察 |
| --- | --- |
| 001、028 | 精修去掉了基线框中的较多胸部区域，脸仍在框内；001 的下缘仍到颈部 |
| 007、041、049 | 脸在框内，但框向下或向侧面延伸到衣服、背景，去脖子策略未触发有效裁剪 |
| 012、018、053、060、063 | 最大肤色候选落在浅色衣服或椅套上，脸未被框住；精修无法修复候选选错的问题 |
| 045 | 右侧红色挂饰被选为候选，属于背景肤色误检 |

本轮说明可分离形态学在保持原算法输出的同时降低单次邻域扫描量；它不会改善肤色阈值和最大连通域造成的误检。下一轮若要提升检出率，应针对候选区域选择和头颈分离提出新策略，并另建一个以新改动命名的结果目录，直接与本轮 63 帧逐帧对照。

## 补充边界用例与构建

在 [synthetic](../fig/iterations/separable-morphology/synthetic/) 中另保存两个从视频帧派生的测试图：将 001 帧整体调暗 0.20 后仍能框到脸；从 045 帧仅保留右侧挂饰、移除人物后的无脸图却仍产生非空框，证明背景误检确实存在。这两张图是人工变换的边界用例，不能替代真实弱光或真实无脸录像。

`Release | Win32` 整个解决方案构建通过，`face_locator_contract` 使用新编译的 Release DLL 通过，确认 Y/U/V 缓冲与插件接口。现有 Debug 程序仍在运行并占用 `PB_FaceLocator.dll`，因此 Debug 构建在链接阶段报 `LNK1168`；编译阶段已通过。

将新编译的 Release DLL 放入 Release 程序的插件目录后，现场连接集成摄像头，单独启用 `ImagePrepare` 和 `FaceLocator`。窗口显示 640×480 视频、脸部矩形框和右上角二值预览，说明新插件在实际摄像头链路中运行。测试完成后已关闭此 Release 窗口；原先的 Debug 调试进程未被关闭。
